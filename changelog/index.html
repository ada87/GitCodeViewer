Changelog

New features and improvements in every release of GitCode Viewer.

1.6.0

  • Meet the AI Assistant: explore repos, track down bugs, explain code, summarize and translate docs. With built-in Office document viewing and file search, your repo becomes your knowledge base.
  • Connect mainstream AI providers with your own API key, or use a custom baseUrl / apiKey.
  • The AI panel blends seamlessly into your workspace and runs in the background without getting in the way of code reading.
  • Customize style, input, and output parameters, with token usage tracking.
  • Create custom actions for one-tap commands in diff, log, and file scenarios.
  • Note: it reads code, generates docs, and explains — it can't modify or run code yet.
  • Plus a smoother experience across the app.

1.5.5 & 1.5.6

  • Polished the iOS experience and added Family Sharing support.

1.5.4

  • Improved the queue waiting experience, with the option to cancel pending tasks.
  • Removed some rarely-used settings; the file tree style is now free and moved to the code/file tree settings.
  • Fixed the Android left-edge drag area blocking line-number taps, and improved overall stability.

1.5.3

  • Swipe from the left edge of the screen to pull out the file tree and browse files faster.
  • New per-file Git Blame to trace the commit history behind every section of code.
  • View a file's source code as it existed in any historical revision.
  • New author annotations show each section's author and latest change, with a direct jump to the commit.

1.5.2

  • Check out any historical version of a repository and browse it like a snapshot.
  • Option to hide the system gesture bar on supported devices for distraction-free reading.
  • Faster, smarter caching for images loaded from the network.
  • More appearance customization options are now available for free.
  • A smoother clone workflow with several known issues fixed.

1.5.1

  • Refreshed colors and visual details for a more comfortable reading experience.
  • Mermaid diagrams now render directly inside Markdown documents.
  • Option to hide the system gesture bar on supported devices.
  • Fixed interaction issues and improved overall stability.

1.5.0

  • GitCode Viewer is now available on iOS through the App Store.
  • Removed all ads — the app is now completely ad-free.
  • Simplified and reorganized settings for a smoother configuration experience.
  • Fixed code outline parsing for some languages.
  • Improved compatibility and stability on the latest Android versions.

1.4.2

  • Refined document preview, with a graceful fallback to open files in a system app when built-in preview is not available.
  • Smoother reading of very large source files.
  • Performance improvements and bug fixes.

1.4.1

  • Preview common Office, PDF, and rich text documents right inside the app.
  • Preview spreadsheets and data files, including Excel, ODS, CSV, and TSV.
  • Clean up repository caches to reclaim storage, and open any document with a system app in one tap.

1.4.0

  • Search code by content or by symbol to find what you need faster.
  • New code outline lets you jump to any function, class, or section inside a file.
  • A smoother workspace experience with multiple issues fixed.

1.3.4

  • Git Log details with file search make it easier to trace how the code changed.
  • See each file's latest commit at a glance and sort files by it.
  • Markdown rendering is faster and smoother to read.
  • General usability refinements and bug fixes.

1.3.3

  • Shallow clone support greatly improves success rates for very large repositories.
  • Browse Git Tags directly inside the app.
  • GitHub Trending now shows the full rankings.
  • Improved Markdown rendering for a better reading experience.
  • Interaction and performance polish with several bug fixes.

1.3.2

  • Refined in-app interactions for a more focused and convenient experience.
  • Improved file tree with a Tree view mode and one-tap file locating.
  • Customize the app icon to your liking.
  • Image caching now saves mobile data when reading documents.
  • Snooze update notifications for a while instead of dismissing them every time.
  • An always-dark theme option, plus better JetBrains theme rendering and bug fixes.

1.3.1

  • More repository card styles and appearance options, including adjustable borders.
  • Syntax highlighting for more programming languages, including C#, TOML, Jinja, Scala, and WAT.
  • Customize how the workspace handles the back action to match your habits.
  • Now available in Indonesian and Turkish.
  • Performance tuning for smoother everyday use.

1.3.0

  • Brand-new interaction design with a cleaner, smoother experience.
  • Multiple theme palettes and interaction customization, plus fullscreen code reading.
  • Discover GitHub Trending and browse your own repositories.
  • Repository storage management and health checks keep local copies tidy.
  • A reading experience optimized for tablets.
  • Further performance improvements and bug fixes.

1.2.0

  • Connect to repositories over SSH, with Git performance close to desktop level.
  • A new commit diff viewer for reviewing changes line by line.
  • Richer Mermaid diagram rendering, including flowcharts and sequence diagrams.
  • Markdown upgrades: LaTeX math formulas and a floating table of contents that follows your reading.
  • Browse branches and commit logs, with a badge when the remote repository has new updates.
  • Automatic update checks, plus storage usage viewing and cleanup.
  • Performance optimizations and bug fixes.

Pensé pour lire le code sérieusement

Chaque fonction poursuit le même objectif : mieux comprendre le code sur un petit écran.

Git comme sur ordinateur

Clone, pull, branches, historique, tags, checkout et différences dans une interface fluide. Le clone superficiel simplifie les très grands dépôts.

Blame et historique

Le Blame en ligne et les auteurs permettent de remonter chaque ligne à son commit. Ouvrez un fichier à n'importe quelle révision.

Plus de 30 langages

Coloration, plan et symboles grâce à Tree-sitter, pour le code et les fichiers de configuration, avec recherche de texte et d'identifiants.

Documents et notebooks

Lisez PDF, Word, Excel, PowerPoint, CSV et Jupyter dans l'app. Markdown prend en charge Mermaid, LaTeX et une table des matières flottante.

Découvrir GitHub

Tendances et recherche intégrées : trouvez un projet intéressant et clonez-le directement dans votre liste.

Tous vos services Git

GitHub, GitLab, Bitbucket, Azure DevOps, Gitea, Gitee, CNB et serveurs auto-hébergés, via SSH ou jeton d'accès.

Conçu pour le hors-ligne

Clonez une fois, lisez partout. Le code, les documents et l'historique restent accessibles sans réseau.

Thèmes et icônes

Adaptez les thèmes, les cartes de dépôt, la lecture plein écran et l'icône de l'application à vos habitudes.

La confidentialité d'abord

Ni statistiques, ni suivi, ni télémétrie. Les échanges se font directement entre votre appareil et votre service Git.

Questions fréquentes

Vous avez une autre question ? Écrivez-nous.

GitCode Viewer est-il gratuit ?

Oui, sans création de compte. Certaines fonctions avancées font partie de la version premium.

Quels langages sont pris en charge ?

La coloration couvre plus de 30 langages et plus de 100 extensions. Les principaux langages disposent aussi d'un plan et de la navigation par symboles.

Quels documents puis-je ouvrir ?

Markdown, PDF, Word, Excel, PowerPoint, RTF, CSV, TSV, Mermaid et Jupyter.

Quels services Git sont compatibles ?

GitHub, GitLab, Bitbucket, Azure DevOps, Gitea, Gitee, CNB et les serveurs Git auto-hébergés.

SSH et les dépôts privés sont-ils pris en charge ?

Oui. Utilisez SSH ou un jeton ; les identifiants restent uniquement sur votre appareil.

Puis-je lire mes dépôts hors ligne ?

Oui. Après le clonage, code, documents et historique Git restent accessibles hors ligne.

La version premium est-elle partagée entre Android et iOS ?

Non. Les achats sont gérés séparément par chaque boutique.

L'application collecte-t-elle des données ?

Non. Elle n'utilise ni statistiques, ni suivi, ni télémétrie.

À propos de GitCode Viewer

GitCode Viewer est un client Git mobile conçu pour une chose : lire le code sérieusement. Clonez, retracez et comprenez vos projets où que vous soyez.

Git sur mobile, comme sur ordinateur

Les opérations Git essentielles restent fluides sur mobile, y compris pour les grands dépôts grâce au clone superficiel.

Retracer l'origine du code

Blame en ligne, auteurs et révisions historiques facilitent l'analyse des changements sans ordinateur.

Lire tous les fichiers du dépôt

Code, configuration, Markdown, PDF, fichiers Office et notebooks Jupyter s'ouvrent directement dans le dépôt.

Connecter vos services Git

Les principaux services et les serveurs auto-hébergés sont pris en charge, y compris sur un intranet, via SSH ou jeton.

Hors ligne et confidentiel

Une fois clonés, code, documents et historique restent disponibles hors ligne. Aucune donnée d'utilisation n'est collectée. Consultez la politique de confidentialité.

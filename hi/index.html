दस्तावेज़ और notebooks

PDF, Word, Excel, PowerPoint, CSV और Jupyter ऐप में पढ़ें। Markdown में Mermaid, LaTeX और floating contents मिलते हैं।

AI कोड से आगे भी पढ़ता है

दस्तावेज़ खोलें, कमिट इतिहास देखें और सीखी हुई बातें नोट्स में सेव करें — बस आम भाषा में बता दें कि क्या चाहिए।

ऑफ़लाइन को प्राथमिकता

एक बार क्लोन करें, फिर कहीं भी पढ़ें। कोड, दस्तावेज़ और Git हिस्ट्री बिना नेटवर्क भी उपलब्ध रहते हैं।

Blame और हिस्ट्री

हर लाइन के commit और लेखक को देखें। किसी भी पुराने revision की फ़ाइल खोलें या एक टैप में checkout करें।

प्राइवेसी सबसे पहले

कोई analytics, tracking या telemetry नहीं। ट्रैफ़िक सीधे आपके डिवाइस और Git सेवा के बीच जाता है।

सामान्य सवाल

कोई और सवाल है? हमसे संपर्क करें.

क्या GitCode Viewer मुफ़्त है?

हाँ, इसके लिए अकाउंट नहीं चाहिए। कुछ उन्नत फ़ीचर premium version में मिलते हैं।

कौन-सी भाषाएँ और फ़ाइल फ़ॉर्मैट समर्थित हैं?

30+ प्रोग्रामिंग भाषाओं और 100+ extensions के लिए हाइलाइटिंग है। प्रमुख भाषाओं में outline और symbol navigation भी मिलता है।

कौन-से दस्तावेज़ खोले जा सकते हैं?

Markdown, PDF, Word, Excel, PowerPoint, RTF, CSV, TSV, Mermaid और Jupyter।

क्या यह AI सेवाएँ प्रदान करता है?

नहीं। AI सुविधा के लिए आपको अपनी API key लानी होगी। ऐप पूरी तरह ऑफ़लाइन है — आपकी key एन्क्रिप्ट होकर केवल आपके फ़ोन पर रहती है, कहीं भेजी नहीं जाती, और सेव होने के बाद दोबारा नहीं देखी जा सकती।

क्या AI असिस्टेंट मेरा कोड बदल सकता है?

नहीं। AI असिस्टेंट कोड समझने, सीखने, खोजने और तलाशने में मदद करता है, लेकिन कोड बदल या चला नहीं सकता। इसके लिए Codex या Claude Code जैसे डेस्कटॉप टूल इस्तेमाल करने की सलाह है।

AI इस्तेमाल करने की कोई टिप?

कोड पढ़ने के अलावा, AI Office / PDF दस्तावेज़ पढ़ सकता है, Git कमिट इतिहास देख सकता है और दस्तावेज़ सेव कर सकता है। आपको जो चाहिए वह सामान्य भाषा में बताइए, AI खुद इन क्षमताओं का इस्तेमाल कर लेगा।

कौन-सा AI मॉडल चुनूँ?

चूँकि ऐप खुद कोड नहीं लिखता, अच्छी कीमत वाला आम मॉडल ही काफ़ी है और इससे token का खर्च कम रहता है। thinking / streaming सपोर्ट करने वाले मॉडल चुनने की सलाह है।

कौन-सी Git सेवाएँ समर्थित हैं?

GitHub, GitLab, Bitbucket, Azure DevOps, Gitea, Gitee, CNB और self-hosted Git server।

क्या SSH और प्राइवेट रिपॉज़िटरी समर्थित हैं?

हाँ। SSH या access token इस्तेमाल करें; credentials केवल आपके डिवाइस पर रहते हैं।

क्या रिपॉज़िटरी ऑफ़लाइन पढ़ सकते हैं?

हाँ। क्लोन के बाद कोड, दस्तावेज़ और पूरी Git हिस्ट्री ऑफ़लाइन उपलब्ध रहती है।

क्या premium Android और iOS दोनों पर चलता है?

नहीं। खरीदारी हर ऐप स्टोर पर अलग से प्रबंधित होती है।

क्या ऐप उपयोगकर्ता डेटा इकट्ठा करता है?

नहीं। कोई analytics, tracking या telemetry इस्तेमाल नहीं होती।

मोबाइल पर कोड पढ़ना शुरू करें

मुफ़्त, बिना अकाउंट के, और फ़ोन व टैबलेट दोनों के लिए अनुकूलित।

GitCode Viewer के बारे में

GitCode Viewer एक मोबाइल Git क्लाइंट है जो एक काम पर केंद्रित है: कोड को गंभीरता से पढ़ना। कहीं भी प्रोजेक्ट क्लोन करें, बदलाव समझें और कोड की तह तक जाएँ।

मोबाइल पर डेस्कटॉप जैसा Git

ज़रूरी Git workflow मोबाइल पर सहज रहते हैं। Shallow clone से बहुत बड़े रिपॉज़िटरी भी आसानी से संभाले जा सकते हैं।

एडिटर नहीं, पढ़ने का टूल

GitCode Viewer एडिटिंग या कोड चलाने पर ध्यान नहीं देता - यह सिर्फ़ रिपॉज़िटरी को सिंक करता है, ताकि आप ब्रांच और हिस्ट्री आज़ादी से बदल सकें, और सर्च व outline डेस्कटॉप IDE जैसे मिलें। AI असिस्टेंट सिर्फ़ कोड समझने और सीखने में मदद करता है, और टैबलेट अनुभव खासतौर पर IDE जैसा बनाया गया है।

कोड की हिस्ट्री समझें

लाइन-दर-लाइन Blame, लेखक की जानकारी और पुराने revision से कंप्यूटर के बिना भी बदलावों की जाँच करें।

रिपॉज़िटरी की हर फ़ाइल पढ़ें

कोड, config, Markdown, PDF, Office दस्तावेज़ और Jupyter notebooks रिपॉज़िटरी में ही खोलें।

अपनी Git सेवाएँ जोड़ें

लोकप्रिय सेवाओं और अपने सर्वर को, intranet पर भी, SSH या access token के ज़रिए इस्तेमाल करें।

ऑफ़लाइन और निजी

क्लोन करने के बाद कोड, दस्तावेज़ और हिस्ट्री ऑफ़लाइन उपलब्ध रहते हैं। हम उपयोग का डेटा इकट्ठा नहीं करते। पढ़ें प्राइवेसी पॉलिसी.

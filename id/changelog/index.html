Yang baru

Fitur dan peningkatan baru di setiap rilis GitCode Viewer.

1.6.0

  • Kenalkan Asisten AI: jelajahi repo, temukan bug, pahami kode, rangkum dan terjemahkan dokumen. Dengan penampil Office dan pencarian file bawaan, repo-mu kini jadi basis pengetahuanmu.
  • Hubungkan penyedia AI populer dengan API key-mu sendiri, atau pakai baseUrl / apiKey kustom.
  • Panel AI menyatu mulus dengan workspace dan berjalan di latar belakang tanpa mengganggu aktivitas membaca kode.
  • Sesuaikan gaya serta parameter input dan output, lengkap dengan statistik pemakaian token.
  • Buat aksi kustom untuk perintah sekali ketuk dalam skenario diff, log, dan file.
  • Catatan: AI membaca kode, membuat dokumen, dan menjelaskan — belum mengubah atau menjalankan kode.
  • Plus: pengalaman yang lebih mulus di seluruh aplikasi.

1.5.5 & 1.5.6

  • Pengalaman iOS disempurnakan dan dukungan Berbagi Keluarga ditambahkan.

1.5.4

  • Pengalaman menunggu dalam antrean ditingkatkan, dengan opsi membatalkan tugas yang tertunda.
  • Menghapus beberapa pengaturan yang jarang dipakai; gaya pohon file kini gratis dan dipindah ke pengaturan kode/pohon file.
  • Memperbaiki area geser di tepi kiri Android yang menghalangi ketukan nomor baris, serta meningkatkan stabilitas.

1.5.3

  • Geser dari tepi kiri layar untuk membuka pohon file dan menjelajah file lebih cepat.
  • Git Blame per file baru untuk menelusuri riwayat commit di balik setiap bagian kode.
  • Lihat kode sumber file sebagaimana adanya pada revisi historis mana pun.
  • Anotasi penulis baru menampilkan penulis dan perubahan terakhir setiap bagian, dengan lompatan langsung ke commit.

1.5.2

  • Buka versi historis mana pun dari sebuah repo dan jelajahi seperti snapshot.
  • Opsi menyembunyikan bilah gestur sistem di perangkat yang didukung untuk membaca tanpa gangguan.
  • Caching gambar jaringan yang lebih cepat dan cerdas.
  • Lebih banyak opsi kustomisasi tampilan kini tersedia gratis.
  • Alur clone yang lebih mulus dengan beberapa masalah yang diketahui telah diperbaiki.

1.5.1

  • Warna dan detail visual disegarkan untuk pengalaman membaca yang lebih nyaman.
  • Diagram Mermaid kini dirender langsung di dalam dokumen Markdown.
  • Opsi menyembunyikan bilah gestur sistem di perangkat yang didukung.
  • Memperbaiki masalah interaksi dan meningkatkan stabilitas secara keseluruhan.

1.5.0

  • GitCode Viewer kini tersedia di iOS melalui App Store.
  • Semua iklan dihapus — aplikasi kini sepenuhnya bebas iklan.
  • Pengaturan disederhanakan dan ditata ulang untuk pengalaman konfigurasi yang lebih mulus.
  • Memperbaiki penguraian garis besar kode untuk beberapa bahasa.
  • Meningkatkan kompatibilitas dan stabilitas pada versi Android terbaru.

1.4.2

  • Pratinjau dokumen disempurnakan, dengan fallback membuka file di aplikasi sistem saat pratinjau bawaan tidak tersedia.
  • Membaca file sumber yang sangat besar kini lebih mulus.
  • Peningkatan performa dan perbaikan bug.

1.4.1

  • Pratinjau dokumen Office, PDF, dan rich text umum langsung di dalam aplikasi.
  • Pratinjau spreadsheet dan file data, termasuk Excel, ODS, CSV, dan TSV.
  • Bersihkan cache repo untuk mengosongkan ruang, dan buka dokumen apa pun dengan aplikasi sistem dalam satu ketukan.

1.4.0

  • Cari kode berdasarkan konten atau simbol untuk menemukan yang kamu butuhkan lebih cepat.
  • Garis besar kode baru memungkinkanmu melompat ke fungsi, kelas, atau bagian mana pun dalam file.
  • Pengalaman workspace yang lebih mulus dengan beberapa masalah yang telah diperbaiki.

1.3.4

  • Detail Git Log dengan pencarian file memudahkan pelacakan perubahan kode.
  • Lihat commit terbaru setiap file sekilas dan urutkan file berdasarkan itu.
  • Rendering Markdown lebih cepat dan nyaman dibaca.
  • Penyempurnaan kegunaan umum dan perbaikan bug.

1.3.3

  • Dukungan clone dangkal sangat meningkatkan tingkat keberhasilan untuk repo yang sangat besar.
  • Jelajahi Tag Git langsung di dalam aplikasi.
  • GitHub Trending kini menampilkan peringkat lengkap.
  • Rendering Markdown ditingkatkan untuk pengalaman membaca yang lebih baik.
  • Penyempurnaan interaksi dan performa dengan beberapa perbaikan bug.

1.3.2

  • Interaksi dalam aplikasi disempurnakan untuk pengalaman yang lebih fokus dan nyaman.
  • Pohon file ditingkatkan dengan mode tampilan pohon dan pencarian file sekali ketuk.
  • Sesuaikan ikon aplikasi sesukamu.
  • Caching gambar kini menghemat data seluler saat membaca dokumen.
  • Tunda notifikasi pembaruan untuk sementara alih-alih menutupnya setiap saat.
  • Opsi tema selalu gelap, plus rendering tema JetBrains yang lebih baik dan perbaikan bug.

1.3.1

  • Lebih banyak gaya kartu repo dan opsi tampilan, termasuk batas yang dapat disesuaikan.
  • Penyorotan sintaks untuk lebih banyak bahasa, termasuk C#, TOML, Jinja, Scala, dan WAT.
  • Sesuaikan cara workspace menangani tindakan kembali sesuai kebiasaanmu.
  • Kini tersedia dalam bahasa Indonesia dan Turki.
  • Penyesuaian performa untuk penggunaan sehari-hari yang lebih mulus.

1.3.0

  • Desain interaksi serba baru dengan pengalaman yang lebih bersih dan mulus.
  • Beberapa palet tema dan kustomisasi interaksi, plus pembacaan kode layar penuh.
  • Temukan GitHub Trending dan jelajahi repo milikmu sendiri.
  • Manajemen penyimpanan repo dan pemeriksaan kesehatan menjaga salinan lokal tetap rapi.
  • Pengalaman membaca yang dioptimalkan untuk tablet.
  • Peningkatan performa lebih lanjut dan perbaikan bug.

1.2.0

  • Terhubung ke repo melalui SSH, dengan performa Git mendekati level desktop.
  • Penampil diff commit baru untuk meninjau perubahan baris demi baris.
  • Rendering diagram Mermaid yang lebih kaya, termasuk diagram alur dan diagram urutan.
  • Peningkatan Markdown: rumus matematika LaTeX dan daftar isi mengambang yang mengikuti bacaanmu.
  • Jelajahi branch dan log commit, dengan lencana saat repo jarak jauh punya pembaruan baru.
  • Pemeriksaan pembaruan otomatis, plus melihat dan membersihkan penggunaan penyimpanan.
  • Optimasi performa dan perbaikan bug.

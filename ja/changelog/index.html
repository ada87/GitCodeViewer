更新履歴

GitCode Viewer の各リリースでの新機能と改善点。

1.6.0

  • AIアシスタント登場：リポジトリの探索、バグ探し、コード解説、ドキュメントの要約・翻訳まで。Officeビューアとファイル検索を内蔵し、リポジトリがそのまま知識ベースに。
  • 自分のAPIキーで主要なAIサービスに接続。カスタムのbaseUrl / apiKeyにも対応。
  • AIパネルはワークスペースに自然に溶け込み、バックグラウンドで動作してコード閲覧の邪魔をしない。
  • スタイルや入力・出力パラメータをカスタマイズでき、トークン使用量の統計も確認可能。
  • diff・ログ・ファイルのシーンでワンタップ指示を出すカスタムアクションを作成。
  • 補足：コードを読み、ドキュメントを生成し、解説するところまで。コードの変更・実行にはまだ対応していません。
  • さらに、アプリ全体の操作感もより滑らかに。

1.5.5 & 1.5.6

  • iOSでの体験を改善し、ファミリー共有に対応。

1.5.4

  • キューの待機体験を改善し、保留中のタスクをキャンセルできるように。
  • あまり使われない設定項目を整理。ファイルツリーのスタイルを無料化し、コード/ファイルツリー設定へ移動。
  • Androidで左端のドラッグ領域が行番号のタップを遮っていた問題を修正し、安定性を向上。

1.5.3

  • 画面左端からスワイプしてファイルツリーを引き出し、より速くファイルを閲覧。
  • ファイル単位のGit Blameを新設し、各コード部分のコミット履歴を追跡。
  • 任意の過去リビジョン時点のソースコードをそのまま表示。
  • 新しい著者注釈で各セクションの著者と最新の変更を表示し、該当コミットへワンタップでジャンプ。

1.5.2

  • リポジトリの任意の過去バージョンを開き、スナップショットのように閲覧。
  • 対応デバイスでシステムのジェスチャーバーを隠し、没入感のある読書が可能。
  • ネットワーク画像の読み込みとキャッシュを高速化・改善。
  • 一部の外観カスタマイズが無料に。
  • クローン手順を改善し、既知の問題を修正。

1.5.1

  • 配色と視覚的な細部を刷新し、より快適な読書体験に。
  • Markdownドキュメント内でMermaid図を直接描画。
  • 対応デバイスでシステムのジェスチャーバーを隠すオプションを追加。
  • 操作上の問題を修正し、全体的な安定性を向上。

1.5.0

  • GitCode ViewerがApp StoreでiOS版を公開。
  • 広告をすべて削除し、完全に広告なしに。
  • 設定項目を整理・簡素化し、よりスムーズな設定体験に。
  • 一部言語のコードアウトライン解析を修正。
  • 最新のAndroidバージョンでの互換性と安定性を向上。

1.4.2

  • ドキュメントプレビューを改善し、内蔵プレビューが使えない場合はシステムアプリで開くようフォールバック。
  • 非常に大きなソースファイルの閲覧がよりスムーズに。
  • パフォーマンス改善とバグ修正。

1.4.1

  • アプリ内で一般的なOffice・PDF・リッチテキスト文書をプレビュー。
  • Excel・ODS・CSV・TSVなどの表計算・データファイルをプレビュー。
  • リポジトリのキャッシュを整理して容量を解放し、任意の文書をシステムアプリでワンタップ起動。

1.4.0

  • コードを内容またはシンボルで検索し、より速く目的の場所へ。
  • 新しいコードアウトラインでファイル内の関数・クラスなどへ即ジャンプ。
  • ワークスペース体験を改善し、複数の問題を修正。

1.3.4

  • Git Log詳細とファイル検索で、コードの変更履歴をより追いやすく。
  • 各ファイルの最新コミットを一目で確認し、それで並べ替え。
  • Markdownの描画がより高速で読みやすく。
  • 使い勝手の改善とバグ修正。

1.3.3

  • シャロークローン対応で、超大規模リポジトリのクローン成功率が大幅に向上。
  • アプリ内でGitタグを直接閲覧。
  • GitHub Trendingで完全なランキングを表示。
  • Markdown描画を改善し、より良い読書体験に。
  • 操作感とパフォーマンスを磨き、複数のバグを修正。

1.3.2

  • アプリ内の操作を洗練し、より集中しやすく快適に。
  • ファイルツリーを改善し、ツリー表示モードとワンタップでのファイル特定に対応。
  • アプリアイコンをお好みにカスタマイズ。
  • 画像キャッシュで文書閲覧時のモバイル通信量を節約。
  • 更新通知を毎回閉じる代わりに、しばらくスヌーズ可能に。
  • 常時ダークテーマのオプションを追加し、JetBrainsテーマの表示を改善、バグ修正。

1.3.1

  • リポジトリカードのスタイルと外観オプションを追加（枠線の太さ調整など）。
  • C#・TOML・Jinja・Scala・WATなど、より多くの言語でシンタックスハイライトに対応。
  • ワークスペースの戻る操作を自分の習慣に合わせてカスタマイズ。
  • インドネシア語とトルコ語に対応。
  • 日常使いがより滑らかになるようパフォーマンスを調整。

1.3.0

  • 全く新しい操作デザインで、よりすっきり滑らかな体験に。
  • 複数のテーマパレットと操作カスタマイズ、さらに全画面でのコード閲覧に対応。
  • GitHub Trendingの発見と自分のリポジトリの閲覧が可能。
  • リポジトリのストレージ管理とヘルスチェックでローカルコピーを整理。
  • タブレット向けに最適化された読書体験。
  • さらなるパフォーマンス改善とバグ修正。

1.2.0

  • SSHでリポジトリに接続でき、Git性能はデスクトップ並みに。
  • 新しいコミットDiffビューアで変更を1行ずつ確認。
  • フローチャートやシーケンス図など、Mermaid図の描画を強化。
  • Markdownを強化：LaTeX数式と、読書に追従するフローティング目次に対応。
  • ブランチとコミット履歴を閲覧でき、リモートに更新があるとバッジで表示。
  • 自動更新チェックに加え、ストレージ使用量の確認とクリーンアップに対応。
  • パフォーマンス最適化とバグ修正。

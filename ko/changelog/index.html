업데이트 내역

GitCode Viewer의 각 릴리스에 담긴 새로운 기능과 개선 사항.

1.6.0

  • AI 어시스턴트를 만나보세요: 저장소 탐색, 버그 찾기, 코드 설명, 문서 요약과 번역까지. Office 뷰어와 파일 검색을 내장해 저장소가 곧 나만의 지식 베이스가 됩니다.
  • 주요 AI 서비스를 내 API 키로 연결하거나, 사용자 지정 baseUrl / apiKey를 사용하세요.
  • AI 패널은 워크스페이스에 자연스럽게 통합되어 백그라운드에서 실행되며 코드 읽기를 방해하지 않습니다.
  • 스타일, 입력·출력 파라미터를 취향대로 조정하고 토큰 사용량 통계도 확인하세요.
  • diff, 로그, 파일 시나리오에서 원터치 명령을 실행하는 사용자 지정 액션을 만들 수 있습니다.
  • 참고: 코드를 읽고 문서를 만들고 설명하기까지 합니다. 아직 코드를 수정하거나 실행하지는 않습니다.
  • 덤으로, 앱 전반의 사용 경험도 한층 부드러워졌습니다.

1.5.5 & 1.5.6

  • iOS 사용 경험을 다듬고 가족 공유를 지원합니다.

1.5.4

  • 대기열 대기 경험을 개선하고 보류 중인 작업을 취소할 수 있게 했습니다.
  • 자주 쓰이지 않는 설정 일부를 정리하고, 파일 트리 스타일을 무료화하여 코드/파일 트리 설정으로 이동했습니다.
  • Android에서 왼쪽 가장자리 드래그 영역이 줄 번호 탭을 막던 문제를 수정하고 안정성을 개선했습니다.

1.5.3

  • 화면 왼쪽 가장자리에서 스와이프해 파일 트리를 꺼내 더 빠르게 파일을 탐색하세요.
  • 파일별 Git Blame을 새로 추가해 코드 구간마다 커밋 이력을 추적할 수 있습니다.
  • 파일의 소스 코드를 과거 리비전 상태 그대로 확인하세요.
  • 새 저자 주석으로 각 구간의 작성자와 최근 변경을 확인하고 해당 커밋으로 바로 이동할 수 있습니다.

1.5.2

  • 저장소의 과거 버전을 열어 스냅샷처럼 탐색하세요.
  • 지원 기기에서 시스템 제스처 바를 숨겨 방해 없이 읽을 수 있습니다.
  • 네트워크 이미지 로딩과 캐싱을 더 빠르고 똑똑하게 개선했습니다.
  • 더 많은 외관 사용자 지정 옵션을 무료로 제공합니다.
  • 클론 흐름을 개선하고 여러 알려진 문제를 수정했습니다.

1.5.1

  • 색상과 시각적 디테일을 다듬어 더 편안한 읽기 경험을 제공합니다.
  • Markdown 문서에서 Mermaid 다이어그램을 바로 렌더링합니다.
  • 지원 기기에서 시스템 제스처 바를 숨기는 옵션을 제공합니다.
  • 상호작용 문제를 수정하고 전반적인 안정성을 개선했습니다.

1.5.0

  • GitCode Viewer가 App Store를 통해 iOS에서 출시되었습니다.
  • 모든 광고를 제거해 이제 완전히 광고 없이 사용할 수 있습니다.
  • 설정을 간소화하고 재구성해 더 매끄럽게 구성할 수 있습니다.
  • 일부 언어의 코드 아웃라인 파싱을 수정했습니다.
  • 최신 Android 버전에서의 호환성과 안정성을 개선했습니다.

1.4.2

  • 문서 미리보기를 다듬고, 내장 미리보기를 사용할 수 없을 때 시스템 앱으로 열도록 했습니다.
  • 매우 큰 소스 파일을 더 부드럽게 읽을 수 있습니다.
  • 성능 개선과 버그 수정.

1.4.1

  • 일반적인 Office, PDF, 서식 있는 텍스트 문서를 앱 안에서 바로 미리봅니다.
  • Excel, ODS, CSV, TSV 등 스프레드시트와 데이터 파일을 미리봅니다.
  • 저장소 캐시를 정리해 공간을 확보하고, 어떤 문서든 시스템 앱으로 한 번에 열 수 있습니다.

1.4.0

  • 코드를 내용이나 심볼로 검색해 필요한 것을 더 빨리 찾으세요.
  • 새 코드 아웃라인으로 파일 안의 함수, 클래스, 섹션으로 바로 이동할 수 있습니다.
  • 워크스페이스 경험을 개선하고 여러 문제를 수정했습니다.

1.3.4

  • Git Log 세부 정보와 파일 검색으로 코드 변경 이력을 더 쉽게 추적할 수 있습니다.
  • 각 파일의 최근 커밋을 한눈에 확인하고 그 기준으로 정렬하세요.
  • Markdown 렌더링이 더 빠르고 읽기 편해졌습니다.
  • 전반적인 사용성 개선과 버그 수정.

1.3.3

  • 얕은 복제 지원으로 매우 큰 저장소의 복제 성공률이 크게 향상되었습니다.
  • 앱에서 Git 태그를 바로 탐색하세요.
  • GitHub Trending에서 전체 순위를 확인할 수 있습니다.
  • Markdown 렌더링을 개선해 읽기 경험을 높였습니다.
  • 상호작용과 성능을 다듬고 여러 버그를 수정했습니다.

1.3.2

  • 앱 내 상호작용을 다듬어 더 집중되고 편리한 경험을 제공합니다.
  • 파일 트리를 개선해 트리 보기 모드와 원터치 파일 찾기를 지원합니다.
  • 앱 아이콘을 취향에 맞게 꾸밀 수 있습니다.
  • 이미지 캐싱으로 문서를 읽을 때 모바일 데이터를 아낄 수 있습니다.
  • 업데이트 알림을 매번 닫는 대신 잠시 미룰 수 있습니다.
  • 항상 다크 테마 옵션과 함께 JetBrains 테마 렌더링 개선 및 버그 수정.

1.3.1

  • 저장소 카드 스타일과 외관 옵션을 더 추가하고, 테두리 두께도 조절할 수 있습니다.
  • C#, TOML, Jinja, Scala, WAT 등 더 많은 언어의 구문 강조를 지원합니다.
  • 워크스페이스의 뒤로 가기 동작을 사용 습관에 맞게 설정하세요.
  • 인도네시아어와 터키어를 지원합니다.
  • 일상 사용이 더 부드러워지도록 성능을 다듬었습니다.

1.3.0

  • 완전히 새로운 상호작용 디자인으로 더 깔끔하고 매끄러운 경험을 제공합니다.
  • 여러 테마 팔레트와 상호작용 사용자 지정, 전체 화면 코드 읽기를 지원합니다.
  • GitHub Trending을 발견하고 내 저장소를 둘러보세요.
  • 저장소 스토리지 관리와 상태 점검으로 로컬 복사본을 깔끔하게 유지합니다.
  • 태블릿에 최적화된 읽기 경험을 제공합니다.
  • 추가 성능 개선과 버그 수정.

1.2.0

  • SSH로 저장소에 연결할 수 있으며, Git 성능은 데스크톱 수준에 가깝습니다.
  • 새 커밋 diff 뷰어로 변경 사항을 한 줄씩 검토하세요.
  • 순서도와 시퀀스 다이어그램 등 Mermaid 다이어그램 렌더링을 강화했습니다.
  • Markdown 개선: LaTeX 수식과 읽기를 따라오는 플로팅 목차를 지원합니다.
  • 브랜치와 커밋 기록을 탐색하고, 원격 저장소에 새 업데이트가 있으면 배지로 표시합니다.
  • 자동 업데이트 확인과 스토리지 사용량 확인 및 정리를 지원합니다.
  • 성능 최적화와 버그 수정.

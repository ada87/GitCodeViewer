코드를 제대로 읽기 위한 도구

작은 화면에서도 코드를 더 빠르게 이해할 수 있도록 모든 기능을 설계했습니다.

데스크톱급 Git

Clone, Pull, Branch, Log, Tag, Checkout, Diff를 익숙한 흐름으로 사용할 수 있습니다. 대형 저장소에는 얕은 클론을 활용하세요.

Blame과 변경 이력

줄 단위 Blame과 작성자 정보로 각 코드의 커밋을 추적하고, 원하는 리비전의 파일을 열거나 체크아웃할 수 있습니다.

30개 이상의 언어

Tree-sitter 기반 구문 강조, 코드 개요, 심볼 이동을 제공하며 코드와 식별자 검색도 지원합니다.

문서와 Notebook

PDF, Word, Excel, PowerPoint, CSV, Jupyter를 앱 안에서 읽으세요. Markdown은 Mermaid, LaTeX, 플로팅 목차를 지원합니다.

GitHub 프로젝트 찾기

내장된 트렌드와 검색으로 프로젝트를 찾고 읽기 목록에 바로 클론할 수 있습니다.

다양한 Git 서비스

GitHub, GitLab, Bitbucket, Azure DevOps, Gitea, Gitee, CNB와 자체 서버에 SSH 또는 토큰으로 연결합니다.

오프라인 우선

한 번 클론하면 어디서든 읽을 수 있습니다. 코드, 문서, Git 이력이 네트워크 없이도 유지됩니다.

테마와 앱 아이콘

테마, 저장소 카드, 전체 화면 읽기, 앱 아이콘을 원하는 방식으로 설정할 수 있습니다.

개인정보 보호 우선

분석, 추적, 텔레메트리가 없습니다. 통신은 기기와 Git 서비스 사이에서만 이루어집니다.

자주 묻는 질문

더 궁금한 점이 있나요? 문의하기.

GitCode Viewer는 무료인가요?

네. 가입 없이 사용할 수 있으며 일부 고급 기능은 프리미엄 버전에서 제공됩니다.

어떤 언어와 파일 형식을 지원하나요?

30개 이상의 프로그래밍 언어와 100개 이상의 확장자에 구문 강조를 제공하며, 주요 언어는 코드 개요와 심볼 이동도 지원합니다.

어떤 문서를 열 수 있나요?

Markdown, PDF, Word, Excel, PowerPoint, RTF, CSV, TSV, Mermaid, Jupyter를 지원합니다.

어떤 Git 서비스를 지원하나요?

GitHub, GitLab, Bitbucket, Azure DevOps, Gitea, Gitee, CNB와 자체 Git 서버를 지원합니다.

SSH와 비공개 저장소를 지원하나요?

네. SSH 또는 액세스 토큰을 사용할 수 있으며 인증 정보는 기기에만 저장됩니다.

오프라인으로 저장소를 읽을 수 있나요?

네. 클론 후에는 코드, 문서와 전체 Git 이력을 오프라인으로 사용할 수 있습니다.

프리미엄을 Android와 iOS에서 함께 쓸 수 있나요?

아니요. 구매는 각 앱 스토어에서 별도로 관리됩니다.

사용자 데이터를 수집하나요?

아니요. 분석, 추적, 텔레메트리를 수집하지 않습니다.

모바일에서 코드 읽기 시작

가입 없이 무료로 사용할 수 있으며 휴대폰과 태블릿에 최적화되어 있습니다.

GitCode Viewer 소개

GitCode Viewer는 코드를 제대로 읽는 데 집중한 모바일 Git 클라이언트입니다. 어디서든 저장소를 클론하고, 변경을 추적하고, 프로젝트를 이해하세요.

모바일의 데스크톱급 Git

필수 Git 작업을 모바일에서도 자연스럽게 처리하며, 얕은 클론으로 대형 저장소도 부담 없이 다룰 수 있습니다.

코드 변경의 맥락 추적

줄 단위 Blame, 작성자 정보, 과거 리비전으로 컴퓨터 없이도 변경 이유를 확인할 수 있습니다.

저장소의 모든 파일 읽기

코드, 설정 파일, Markdown, PDF, Office 문서와 Jupyter Notebook을 저장소 안에서 바로 엽니다.

Git 서비스 연결

주요 Git 서비스와 자체 서버를 지원하며 사내망에서도 SSH 또는 토큰으로 연결할 수 있습니다.

오프라인과 개인정보 보호

클론 후에는 코드, 문서, 이력을 오프라인으로 읽을 수 있습니다. 사용 데이터는 수집하지 않습니다. 자세한 내용은 개인정보 처리방침.

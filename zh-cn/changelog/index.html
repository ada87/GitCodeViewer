GitCode Viewer 每个版本的新功能与改进

1.6.0

  • AI 助手上线：探索仓库、定位 Bug、解释代码、总结与翻译文档，内置 Office 文档阅读和文件搜索，你的仓库就是你的知识库。
  • 支持主流 AI 服务商以 API Key 接入，也支持自定义 baseUrl / apiKey。
  • AI 面板无缝融入工作区，后台运行，不干扰代码查看。
  • 支持自定义风格、输入输出等参数，并提供 Token 用量统计。
  • 支持自定义动作，diff / log / 文件场景一键下达指令。
  • 说明：目前支持读代码、生成文档与理解，暂不支持修改 / 运行代码。
  • 优化整体流程体验，使用更顺畅。

1.5.5 & 1.5.6

  • 优化 iOS 上的体验问题，支持家庭共享。

1.5.4

  • 优化队列等待交互，支持取消排队任务。
  • 移除部分少用配置项，文件树样式改为免费功能并移至代码/文件树设置。
  • 修复 Android 左侧拖拽热区遮挡代码行号点击的问题，提升应用稳定性。

1.5.3

  • 支持从屏幕左侧快速拉出文件树，浏览文件更加便捷
  • 新增文件级 Git Blame，快速追溯每段代码的提交记录
  • 支持直接查看文件在任意历史版本中的源码
  • 新增代码作者注解，可查看作者与最近修改并一键跳转到对应提交

1.5.2

  • 支持切换到仓库的任意历史版本进行浏览
  • 支持在部分设备上隐藏系统手势条，阅读更沉浸
  • 优化网络图片的加载与缓存
  • 部分外观自定义选项转为免费
  • 优化 Clone 流程并修复已知问题

1.5.1

  • 优化界面配色与视觉细节，阅读更加舒适
  • Markdown 现已支持直接渲染 Mermaid 图表
  • 支持在部分设备上隐藏系统手势条
  • 修复部分交互问题并提升稳定性

1.5.0

  • GitCode Viewer 正式登陆 App Store，iOS 版上线
  • 移除全部广告，应用完全无广告
  • 精简并重新归类设置项，配置体验更顺畅
  • 修复部分语言的代码大纲解析问题
  • 提升在新版 Android 系统上的兼容性与稳定性

1.4.2

  • 优化文档预览体验，无法内置预览的文件可一键改用系统应用打开
  • 超大代码文件的阅读更加流畅
  • 性能优化与问题修复

1.4.1

  • 新增文档预览，支持常见 Office、PDF 与富文本文件
  • 新增表格与数据文件预览，支持 Excel、ODS、CSV、TSV
  • 支持清理仓库缓存释放空间，并可从预览页直接用系统应用打开文档

1.4.0

  • 新增代码内容搜索与符号搜索，更快定位代码
  • 新增代码大纲，可在文件内快速跳转到函数、类等位置
  • 优化工作区体验并修复若干问题

1.3.4

  • 支持 Git Log 详情与文件搜索，更高效地追踪代码变更
  • 可直接查看每个文件的最近提交信息并支持排序
  • 优化 Markdown 渲染交互与性能，阅读体验更顺滑
  • 持续打磨整体使用体验并修复若干问题

1.3.3

  • 支持浅克隆，超大仓库的克隆成功率显著提升
  • 支持在应用内直接查看 Git Tags
  • GitHub 热榜现已支持查看完整榜单
  • 优化 Markdown 渲染，阅读体验更好
  • 持续优化交互与性能并修复若干问题

1.3.2

  • 重构应用内交互，使用体验更聚焦也更顺手
  • 优化文件树样式，支持 Tree 模式与一键定位文件
  • 支持自定义应用图标
  • 新增图片缓存，阅读文档更省流量
  • 支持在一段时间内忽略更新通知
  • 新增始终深色主题选项，并优化 JetBrains 主题显示、修复若干问题

1.3.1

  • 支持更多仓库卡片样式与外观参数，包括自定义边框粗细
  • 新增 C#、TOML、Jinja、Scala、WAT 等语言的语法高亮
  • 工作区的后退交互行为可按使用习惯自定义
  • 新增印尼语与土耳其语支持
  • 持续优化性能，整体操作更顺滑

1.3.0

  • 全新交互设计，界面更美观、操作更流畅
  • 支持多套主题配色与交互自定义，新增全屏代码阅读
  • 新增 GitHub 热榜与个人仓库浏览
  • 支持仓库存储管理与健康度检查
  • 针对平板设备进行专项优化
  • 进一步优化性能并修复已知问题

1.2.0

  • 支持通过 SSH 连接仓库，Git 性能接近桌面级体验
  • 新增提交 Diff 查看器，逐行审阅代码变更
  • 增强 Mermaid 图表渲染，支持流程图、时序图等
  • Markdown 升级：支持 LaTeX 数学公式与浮动跟随的目录导航
  • 支持查看分支与提交记录，远程仓库有新更新时显示红点提醒
  • 支持自动检查更新，以及占用空间查看与清理
  • 性能优化与问题修复

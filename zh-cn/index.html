GitCode Viewer 免费吗？

免费，无需注册即可使用；部分高级功能需升级到高级版解锁。

支持哪些编程语言和代码格式？

语法高亮覆盖 30+ 种编程语言、100+ 种文件扩展名；主流语言（C、C++、C#、Go、Rust、Java、Python、JavaScript、TypeScript、PHP、Bash 等）还支持代码大纲与符号跳转。

可以预览哪些文档格式？

Markdown、PDF、Word、Excel、PPT、RTF、CSV / TSV、Mermaid 图表和 Jupyter 笔记本。

支持哪些 Git 平台？

GitHub、GitLab、Bitbucket、Azure DevOps、Gitea、Gitee、CNB，以及自建 Git 服务器——包括内网环境。

支持 SSH 和私有仓库吗？

支持。可以通过 SSH 或访问令牌连接，凭据只保存在你的设备上。

可以离线阅读仓库吗？

可以。克隆之后，代码、文档和完整 Git 历史全部离线可用。

Android 和 iOS 的高级版互通吗？

不互通。高级版经由各应用商店结算，在 Google Play 上升级的无法在 iOS 上使用，反之亦然；换平台需要在对应商店重新升级一次。

GitCode Viewer 会收集用户数据吗？

不会。没有统计、没有追踪、没有遥测，网络流量只在你的设备和你的 Git 平台之间传输。

关于 GitCode Viewer

GitCode Viewer 是一款只为一件事而生的移动端 Git 客户端：认真读代码。它把电脑上的 Git 与 IDE 阅读体验带到手机和平板上——克隆、阅读、追溯、理解，随时随地。

手机上的桌面级 Git

Clone、Pull、Branch、Log、Tag、Checkout、Diff，流畅度向桌面客户端看齐。浅克隆让超大仓库在手机上也可行。

像在桌面端一样追溯代码

行内 Git Blame、作者注解、一键 checkout 到历史版本、查看任意文件在任意历史时刻的源码——不用打开电脑也能做代码考古。

读遍仓库里的每一种文件

tree-sitter 驱动的高亮、大纲与符号覆盖 30+ 编程语言和 10+ 配置格式；原生引擎就地预览 PDF、Word、Excel、PPT、CSV 和 Jupyter 笔记本；Markdown 渲染支持 Mermaid 图表、LaTeX 公式与浮动目录。

接入所有 Git 平台

GitHub、GitLab、Bitbucket、Azure DevOps、Gitea、Gitee、CNB，以及内网里的自建服务器。通过 SSH 或访问令牌连接，凭据只保存在你的设备上。

离线与隐私

克隆之后，代码、文档和完整历史全部离线可用。GitCode Viewer 不收集任何用户数据——没有统计、没有追踪、没有遥测，你的代码和凭据永远不会离开你的设备。阅读完整的 隐私政策.
